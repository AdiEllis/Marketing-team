# מה להעלות כדי לקבל את התוצאה הכי טובה (מדריך קצר לבעלת העסק)

1. **מקור, לא צילום מסך:** בוואטסאפ, "+" ← "מסמך" ← בוחרים את התמונה מהגלריה.
2. **העבודה כולה:** תמונה אחת חזיתית וישרה מרחוק (עדשה רגילה 1x, טלפון ישר, לא מוטה), ועוד זווית אחת או שתיים.
3. **זוגות מאותה נקודה בדיוק:** סגור/פתוח, אורות כבויים/דולקים. מצלמים בלי לזוז (נשענים על משהו).
4. **פרטים:** 3–5 תקריבים של חומר, מדפים, ידיות, תאורה ופנים הארון.
5. **סדר ואור:** חדר מסודר, אורות ה-LED דולקים, אור יום. בלי אנשים, ובלי תמונות משפחתיות על המדפים.
6. **וידאו (רשות):** 5–10 שניות איטיות ויציבות, הליכה לאט לאורך העבודה או פתיחת דלת.
7. **משפט אחד:** מה זה, אילו חומרים, ומה הפתרון המיוחד.
