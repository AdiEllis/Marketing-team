# Learning Agent — למידה ושיפור

## עיקרון
**מציע, לא משנה.** הסוכן לא נוגע בכללי המותג או בפרומפטים. הוא מייצר "הצעות שיפור" שמחכות לאישורך, וכל שינוי מאושר נשמר כגרסת פרומפט חדשה.

## מה נאסף
- כל משוב חופשי שלך, וסיווגו (טון, טקסט, קצב, מוזיקה, קונספט, עיצוב).
- אישורים ודחיות של קונספטים ותוצרים, כולל **מה בחרת מתוך החלופות**.
- תיקונים: מה שונה בין הגרסה שהוצגה לגרסה שאושרה.
- **יומן מכשירים יצירתיים:** אילו Hooks, מבנים, Moves ומשחקי מילים שימשו בכל פרויקט, כדי למנוע חזרתיות.
- פער בין שופט ה-QA להחלטה שלך (כיול).
- בעתיד: מדדי ביצוע מאינסטגרם ופייסבוק (לא בשלב הראשון).

## מה מופק
- **דוח העדפות** מתעדכן: "אהבת טקסט מינימלי ומעברים רציפים; דחית פעמיים קריינות".
- **הצעות שינוי לפרומפט**, כ-Diff מנומק עם דוגמאות. אושר: נכנס כגרסה. נדחה: נשמר כ"לא לחזור".
- **ספריית "אהבתי":** תוצרים שאישרת, מפורקים לעקרונות באותה שיטה כמו סרטוני ההשראה (Edit Anatomy), **לא כתבניות להעתקה**.
- התראת חזרתיות לסוכן הקריאייטיב ("מסע אנכי שימש בשני הפרויקטים האחרונים").

## מקורות
`ad-creative` Mode 2 ו-Iteration Log (marketingskills); `marketing-council`; עקרון כיול LLM-as-Judge מול החלטות אנושיות.
