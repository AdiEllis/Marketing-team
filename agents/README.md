# צוות הסוכנים — Even & Etz AI Marketing Studio

> סטטוס: **מפרטי תפקיד (Agent Specs), טיוטה v0.1, לפני מימוש.** הפרומפטים הסופיים ייכתבו בשלב 2 על בסיס המפרטים האלה, ויישמרו עם גרסאות.

## עיקרון מנחה: לא כל דבר הוא סוכן

| רכיב | סוג | למה |
|---|---|---|
| Orchestrator | **מכונת מצבים דטרמיניסטית** + Skill קטן של LLM לסיווג בקשות תיקון | תזמור, ניסיונות חוזרים ואישורים צריכים להיות צפויים, לא "יצירתיים" |
| Creative Strategist (Idea) | **סוכן AI** | חשיבה יצירתית ושיפוט |
| Copywriter | **סוכן AI** | שפה, טון ותובנה |
| Producer / Director | **סוכן AI** | תרגום רעיון לתוכנית הפקה מובנית |
| Creator | **שירותי תוכנה דטרמיניסטיים** (FFmpeg, HyperFrames, מעבד פוסטים) + ספקי AI מחליפים | ההפקה צריכה להיות מדויקת, חוזרת וזולה. ה-AI מחליט, הכלים מבצעים |
| QA | **בדיקות אוטומטיות** + **סוכן שופט ויזואלי** | הפרדה בין מה שניתן למדידה לבין שיפוט יצירתי |
| Learning | **סוכן AI במצב הצעות בלבד** | לא משנה כללים בלי אישור |

## ידע משותף שכל סוכן קורא

1. `knowledge/brand/` — זיכרון המותג (ערכים, קהל, טון, לוגו, כללי נאמנות למוצר).
2. `knowledge/inspiration/reference-videos-analysis.md` — **עקרונות** מסרטוני ההשראה וכללי אנטי-העתקה.
3. `docs/research/agent-skill-sources.md` — מקורות המקצועיות שעליהם נשען כל סוכן.

## כלל-על לכל הסוכנים

- **אמת לפני יופי:** אסור להמציא חלוקה פנימית, חומרים, מבנה, מחירים, המלצות או מבצעים.
- **שקיפות:** כל תוצר מסומן כ"רעיון", "בהפקה", "הופק בפועל", "נכשל" או "ממתין לאישור". אין להציג הדמיה כתוצר.
- **פלט מובנה:** כל סוכן מחזיר JSON לפי סכמה (ייכתב בשלב 2), עם נימוק קצר בעברית.
- **השראה ולא תבנית:** כל החלטה יצירתית מנומקת מתוך *החומר של הפרויקט הנוכחי*.
